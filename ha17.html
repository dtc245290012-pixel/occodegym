Bài thực hành: Các cách nhúng CSS vào trang web

Phần 1: Inline Style - Tiêu đề màu xanh dương

Đoạn văn này được định dạng màu đỏ bằng thuộc tính style trực tiếp trong thẻ HTML (Inline CSS).

Phần 2: Internal Style - Tiêu đề màu xanh lá

Đoạn văn này được định dạng màu cam bằng thẻ style trong phần head (Internal CSS).

Phần 3: External Style - Tiêu đề màu tím

Đoạn văn này được định dạng màu xanh ngọc bằng file CSS riêng biệt (External CSS).
